# Electronic Project Showcase
A responsive GitHub Pages-ready website built with HTML, CSS and JavaScript.

## Publish on GitHub Pages
1. Upload all files and the `images` folder to the repository root.
2. Go to Settings → Pages.
3. Source: Deploy from a branch.
4. Branch: `main`, folder: `/ (root)`.
5. Save and open the published Pages URL.

Important: `index.html` must be in the repository root.

## Online images
Project cards use remote Unsplash image URLs, so no image files need to be uploaded to GitHub. Images are loaded from `images.unsplash.com` when the site is opened. One Arduino image URL was verified against its Unsplash photo page, which identifies it as an official Arduino Uno/breadboard photo and states it is free to use under the Unsplash License.
